ПОЛОЖИ СЮДА ДВА ФАЙЛА ШРИФТА:

  inter-medium.ttf
  inter-bold.ttf

Я не могу сгенерировать бинарный .ttf файл в этой сессии (нет доступа
в интернет), поэтому просто скачай шрифт Inter (бесплатный, лицензия
OFL, можно использовать в модах без проблем):

  https://fonts.google.com/specimen/Inter

Скачай "Inter" -> распакуй -> возьми файлы Inter-Medium.ttf и Inter-Bold.ttf
-> переименуй в inter-medium.ttf / inter-bold.ttf -> положи в эту папку
(assets/triaxvisual/font/), заменив этот текстовый файл.

Если хочешь другой шрифт (например Manrope, Rubik, Sora — все с гугл
шрифтов, все бесплатные) — просто подставь другой .ttf с тем же именем,
либо поменяй имена файлов в triax.json.

После этого текст в GUI будет рендериться этим шрифтом (см. ClickGuiScreen —
используется TriaxVisualClient.FONT вместо стандартного майнкрафтовского).
