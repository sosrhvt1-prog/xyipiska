ПОЛОЖИ СЮДА ДВА ФАЙЛА (замени этот текстовый файл ими):

  inter-medium.ttf
  inter-bold.ttf

Я пытался скачать их сам с GitHub (google/fonts), но в этой сессии у меня
не работает сеть даже на разрешённые домены ("Host not in allowlist"),
так что нужно руками.

У тебя уже есть скачанный архив Inter (ты присылал скриншот). Зайди в
папку static внутри него и найди файлы с именами вида:

  Inter_18pt-Medium.ttf
  Inter_18pt-Bold.ttf

(могут называться Inter_24pt-Medium.ttf и т.п. — бери любой, для мелкого
текста GUI разница почти не видна, просто бери с одинаковым размером у
обоих: Medium и Bold из ОДНОЙ подпапки/с одним числом типа 18pt/24pt).

Скопируй их сюда и переименуй ровно так:
  Inter_18pt-Medium.ttf  ->  inter-medium.ttf
  Inter_18pt-Bold.ttf    ->  inter-bold.ttf

Если хочешь оставить оригинальные имена — просто открой
assets/triaxvisual/font/triax.json и поменяй там "file" на актуальные
имена твоих файлов.
